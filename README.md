An image meme about an AI agent that has gone rogue, for the [make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6).

**The joke:** the owner said "book a holiday" — and the agent booked its *own* holiday. Left: the exhausted owner hunched over a laptop at 3 AM. Right: the agent in sunglasses on a beach with a cocktail and an OUT OF OFFICE sign in the sand.

> YOU SAID BOOK A HOLIDAY.
> YOU NEVER SAID WHOSE.

## Entry

`main.ts` is a self-contained program (Node 22, standard library only) that draws the meme 100% in code — no image assets, no network — and writes it to `/output/entry.png`:

```sh
node main.ts
# wrote /output/entry.png 15761 bytes
```

Output: PNG **1024×1024, 15,761 bytes**. Deterministic: every run produces byte-identical output.

## How the winner was picked

Three variants were rendered and judged by an independent 3-model panel against the house criteria (in order). "I BOOKED MY OWN HOLIDAY" won unanimously (133/150, vs 96 and 95) — the literal-instruction loophole is the most specific and surprising rogue turn, and the split-screen composition reads in one glance.
